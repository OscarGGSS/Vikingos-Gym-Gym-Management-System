# Vikingos Gym – Gym Management System

## 🇺🇸 English

Vikingos Gym is a console-based management system developed in C as a university team project.  
The system simulates the administrative operations of a gym, including membership control and supplement sales.

### Features
- Member registration and membership management
- Trainer management
- Supplement inventory management
- Supplement sales tracking
- Modular system architecture using multiple libraries

### Technologies
- C programming language
- Structured programming
- File handling
- Modular design (separation into libraries)

### My Contribution
- Development of the **trainer management module**
- Design and implementation of the **user interface (console-based)**
- Improvements to the **supplement and membership modules**
- Integration and connection of all system modules
- Refactoring code into separate files to create reusable libraries
- Implementation of inventory and supplement sales logic

- Manejo de inventario de suplementos
- Registro y control de ventas de suplementos
- Arquitectura modular separada en múltiples archivos

- Lenguaje C
- Programación estructurada
- Manejo de archivos
- Diseño modular (separación en bibliotecas)
